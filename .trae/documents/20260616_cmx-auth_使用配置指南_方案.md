## 七、v3 更新记录（2026-06-24）

基于最新代码对 USAGE.md 进行 v3 版本更新，主要变更：

### 7.1 新增 API 端点

| 端点 | 说明 |
|------|------|
| `GET /api/auth/me` | 获取当前登录用户完整信息（含昵称、邮箱、角色、权限） |
| `POST /api/auth/api-keys/create` | 创建 API Key（明文仅返回一次） |
| `GET /api/auth/api-keys/list` | 列出 API Key（支持过滤） |
| `POST /api/auth/api-keys/delete` | 删除 API Key |
| `POST /api/auth/api-keys/toggle-status` | 启用 / 禁用 API Key |
| `POST /api/auth/oauth2-clients/create` | 注册 OAuth2 客户端 |
| `GET /api/auth/oauth2-clients/list` | 列出 OAuth2 客户端 |
| `POST /api/auth/oauth2-clients/update` | 更新 OAuth2 客户端（支持重置密钥） |
| `POST /api/auth/oauth2-clients/delete` | 删除 OAuth2 客户端 |

### 7.2 API Key 两层缓存

- **第一层**：`auth:api_key:{key_prefix}` → `ApiKeyEntity`（TTL 60s），位于 `api_key/manager.rs`
- **第二层**：`auth:api_key_ctx:{key_prefix}` → `AuthContext`（TTL 60s），位于 `auth_service_impl.rs::validate_api_key`
- **失效机制**：Pub/Sub 频道 `auth:cache:invalidate` 广播 `api_key:{key_prefix}`，各实例清理两层缓存
- **效果**：缓存命中时跳过全部 4 次 DB 查询，仅做 SHA256 校验
