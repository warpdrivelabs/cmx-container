# 服务降级功能实现计划

## 需求概述

为 cmx-traits 的 lifecycle.rs 添加服务降级的生命周期回调，并在 cmx-plugin 的 downgrade.rs 执行时：
1. 使用 service_storage 更新 cmx_service_define 中的 version 字段
2. 通过发布事件让 cmx-service 更新缓存的服务信息

## 当前代码分析

### 现有生命周期事件
- `plugin_events::INSTALLED` - 插件已安装
- `plugin_events::UPGRADED` - 插件已升级
- `plugin_events::UNINSTALLED` - 插件已卸载

### 现有生命周期回调
- `on_plugin_installed` - 处理安装事件
- `on_plugin_upgraded` - 处理升级事件
- `on_plugin_uninstalled` - 处理卸载事件

### 现有降级流程（downgrade.rs）
降级流程已完成以下步骤：
1. 检查插件存在
2. 检查节点部署记录
3. 查找目标版本信息
4. 更新 cmx_plugin_versions
5. 更新 cmx_plugin_deployments
6. 更新 cmx_plugin 主表
7. 更新 cmx_meta_table_define version 字段
8. 更新注册表
9. 更新缓存
10. 记录审计日志

**缺失部分**：
- 未更新 cmx_service_define 表中的 version 字段
- 未发布 DOWNGRADED 事件

## 实现步骤

```rust
/// 插件已降级 — 通知监听者更新服务定义版本

```

### 步骤 2: 修改 cmx-plugin/src/service/downgrade.rs

#### 2.1 添加依赖注入
在 `DowngradeServiceDeps` 结构体中添加：
```rust
/// 服务存储
pub service_storage: Arc<dyn cmx_traits::ServiceStorage>,
```

#### 2.2 在降级流程中添加服务版本更新
在步骤 6（更新 cmx_plugin 主表）之后，添加更新服务定义版本的逻辑：

```rust
// 步骤 6.2: 更新 cmx_service_define 表中的 version 字段
{
    // 查询该插件的所有服务定义
    let services = self.deps.service_query
        .get_services_by_plugin(&plugin_id)
        .await
        .map_err(|e| PluginError::Database(format!("查询服务定义失败: {}", e)))?;

    // 更新每个服务的版本
    for service in services {
        let mut updated_service = service.clone();
        updated_service.version = request.target_version.clone();
        self.deps.service_storage
            .save_service(&updated_service, Some(txn_guard.txn_id()))
            .await
            .map_err(|e| PluginError::Database(format!("更新服务定义版本失败: {}", e)))?;
    }
}
```

#### 2.3 发布降级事件
在事务提交后，发布 DOWNGRADED 事件：

```rust
// 步骤 11: 发布降级完成事件
let payload = PluginLifecyclePayload::new(&plugin_id, &request.target_version)
    .with_old_version(&old_version)
    .with_install_path(PathBuf::from(&target_version_record.install_path))
    .with_wasm_path(PathBuf::from(&target_version_record.wasm_path));

GlobalEventBus::get()
    .publish(plugin_events::DOWNGRADED, serde_json::to_value(&payload).unwrap())
    .await;
```

#### 2.4 更新 Default 实现
在 `Default for DowngradeService` 中添加 service_storage 字段的初始化。

### 步骤 3: 修改 cmx-service/src/lifecycle_listener.rs

#### 3.1 添加降级事件订阅
在 `register` 方法中添加：

```rust
// 订阅降级事件
let query = self.service_query.clone();
let registry = self.service_registry.clone();
let handler: EventHandler = Arc::new(move |_topic, payload| {
    let query = query.clone();
    let registry = registry.clone();
    tokio::spawn(async move {
        if let Ok(event) = serde_json::from_value::<PluginLifecyclePayload>(payload) {
            Self::handle_downgraded(query, registry, event).await;
        }
    });
});
GlobalEventBus::get().subscribe(plugin_events::DOWNGRADED, handler).await;
```

#### 3.2 实现降级事件处理方法
添加 `handle_downgraded` 方法：

```rust
/// 处理降级事件：更新服务定义缓存中的版本信息
async fn handle_downgraded(
    query: Arc<dyn ServiceQuery>,
    registry: Arc<ServiceRegistry>,
    event: PluginLifecyclePayload,
) {
    info!("处理插件降级事件: {} {} -> {}", event.plugin_id,
        event.old_version.as_deref().unwrap_or("?"), event.version);

    // 降级时重新加载服务定义（逻辑与升级相同）
    Self::handle_installed(query, registry, event).await;
}
```

### 步骤 4: 添加必要的依赖

#### 4.1 在 downgrade.rs 中添加导入

## 实现顺序

1. **cmx-traits/src/lifecycle.rs** - 添加事件常量和 trait 方法
2. **cmx-plugin/src/service/downgrade.rs** - 添加依赖注入和实现逻辑
3. **cmx-service/src/lifecycle_listener.rs** - 添加事件订阅和处理方法

## 注意事项

1. **事务一致性**：服务版本更新必须在同一个事务中完成，确保数据一致性
2. **事件发布时机**：事件必须在事务提交成功后发布，避免发布失败事件
3. **错误处理**：服务版本更新失败应该回滚整个降级操作
4. **日志记录**：添加详细的日志，便于问题排查
5. **向后兼容**：新增的 trait 方法需要提供默认实现或确保所有实现者都更新
