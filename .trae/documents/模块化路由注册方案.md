# 模块化路由注册方案

## 1. 设计目标

将各模块的路由定义下放到 `handlers` 目录下的各模块中，通过 trait 统一注册。路径前缀由各模块自己管理。

## 2. 方案设计

### 2.1 定义 ModuleRoutes Trait

```rust
/// 模块路由 Trait
///
/// 各 handler 模块实现此 trait 来定义自己的路由
pub trait ModuleRoutes {
    /// 注册该模块的路由
    fn routes(self) -> Router<CmxAppState>;

    /// 获取模块前缀路径
    fn prefix() -> &'static str;

    /// 获取模块名称（用于日志/调试）
    fn module_name(&self) -> &'static str;
}
```

### 2.2 Handler 模块实现示例

**table_metadata/mod.rs**:

```rust
//! 表元数据查询 Handler

pub mod handler;

use crate::app_state::CmxAppState;
use crate::routes::traits::ModuleRoutes;
use axum::routing::{get, post};
use axum::Router;

/// TableMetadata 模块路由
pub struct TableMetadataModule;

impl ModuleRoutes for TableMetadataModule {
    fn routes(self) -> Router<CmxAppState> {
        Router::new()
            .route("/get", get(handler::table_metadata_get_by_id))
            .route("/list", post(handler::table_metadata_list))
            .route("/page", post(handler::table_metadata_page))
    }

    fn prefix() -> &'static str {
        "/api/table-metadata"
    }

    fn module_name(&self) -> &'static str {
        "table_metadata"
    }
}
```

**domain/mod.rs**:

```rust
//! 域管理 Handler

pub mod handler;
pub mod crud;

use crate::app_state::CmxAppState;
use crate::routes::traits::ModuleRoutes;
use axum::routing::post;
use axum::Router;

/// Domain 模块路由
pub struct DomainModule;

impl ModuleRoutes for DomainModule {
    fn routes(self) -> Router<CmxAppState> {
        Router::new()
            // CRUD 路由（通过宏生成）
            .merge(self.crud_routes())
            // 自定义路由
            .route("/tree", post(handler::get_tree))
    }

    fn prefix() -> &'static str {
        "/api/domains"
    }

    fn module_name(&self) -> &'static str {
        "domain"
    }
}

impl DomainModule {
    fn crud_routes(self) -> Router<CmxAppState> {
        crate::register_crud_handlers_module!(Router::new(), domain_crud, "")
    }
}
```

## 3. routes.rs 简化

```rust
//! 集中路由注册模块

use crate::app_state::CmxAppState;
use crate::handlers::domain::DomainModule;
use crate::handlers::application::ApplicationModule;
use crate::handlers::module::ModuleModule;
use crate::handlers::sys_datasource::SysDatasourceModule;
use crate::handlers::table_metadata::TableMetadataModule;
use crate::handlers::plugin::PluginModule;
use crate::handlers::service::ServiceModule;
use crate::routes::traits::ModuleRoutes;
use axum::Router;

/// 注册所有 API 路由
pub fn api_routes() -> Router<CmxAppState> {
    Router::new()
        // 各模块自管理完整路径
        .merge(DomainModule.routes())
        .merge(ApplicationModule.routes())
        .merge(ModuleModule.routes())
        .merge(SysDatasourceModule.routes())
        .merge(TableMetadataModule.routes())
        .merge(PluginModule.routes())
        .merge(ServiceModule.routes())
}
```

## 4. 目录结构

```
crates/libs/cmx-api/src/
├── routes/
│   ├── mod.rs
│   ├── routes.rs           # 统一注册入口
│   └── traits.rs           # ModuleRoutes trait
│
└── handlers/
    ├── mod.rs
    ├── domain/
    │   ├── mod.rs          # 实现 ModuleRoutes，定义完整路径
    │   ├── handler.rs
    │   └── crud.rs
    │
    ├── application/
    │   ├── mod.rs          # 实现 ModuleRoutes
    │   ├── handler.rs
    │   └── crud.rs

    │   └── handler.rs

```

## 5. 优点

1. **分散管理**：各模块的路由和路径前缀在本模块管理，便于维护
2. **统一注册**：routes.rs 中只需 `.merge()` 即可，无需关心路径
3. **类型安全**：编译时检查路由完整性
4. **易于扩展**：新增模块只需实现 trait
5. **自包含**：模块完全自包含，外部只需调用

## 6. 可选：使用泛型简化 CRUD 模块

对于 CRUD 模块，可以提供通用实现：

```rust
/// CRUD 模块路由生成器
pub struct CrudModule<MC, Filter, Create, Update> {
    _marker: PhantomData<(MC, Filter, Create, Update)>,
}

impl<MC, Filter, Create, Update> ModuleRoutes for CrudModule<MC, Filter, Create, Update>
where
    MC: DbBmc + 'static,
{
    fn routes(self) -> Router<CmxAppState> {
        Router::new()
            .route("/create", post(crate::rest::handler::create::<MC, Create>))
            .route("/get", get(crate::rest::handler::get::<MC>))
            .route("/update", post(crate::rest::handler::update::<MC, Update>))
            .route("/delete", post(crate::rest::handler::delete::<MC>))
            .route("/list", post(crate::rest::handler::list::<MC, Filter>))
            .route("/page", post(crate::rest::handler::page::<MC, Filter>))
    }

    fn prefix() -> &'static str {
        // 从 MC::TABLE 生成，如 "user" -> "/api/users"
        let table = MC::TABLE;
        format!("/api/{}", table)
    }
}
```
