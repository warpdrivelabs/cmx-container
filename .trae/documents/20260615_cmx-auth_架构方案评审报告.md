## 二、新发现的问题

### N21.【P1】§11.2 `DataSet` 没有 `first_row()` 方法，编译失败

**代码实测**（`crates/libs/cmx-core/src/model/data/dataset/rds.rs`）：

`DataSet` 的方法列表：`new`/`empty`/`with_capacity`/`add_row`/`row_count`/`is_empty`/`iter`/`from_json_array`/`validate_all` —— **没有 `first_row()`**。

**方案 §11.2 的错误写法**（2099/2128 行）：

```rust
let existing = result.first_row(); // 从 DataSet 取第一条
// ...
let admin_role = result.first_row();
```

**修正建议**：改为 `dataset.iter().next()`，返回 `Option<&Row>`。项目中已有此模式（`cmx-service/src/repository.rs:150`）：

```rust
let row = dataset.iter().next();
```

### N22.【P1】§11.2 `FilterNode` 构造方式错误 + `Row` 字段访问语法不存在

#### N22-a：`FilterNode::from(("username", Equal, &sa.username))` 三元组不存在

**代码实测**（`crates/libs/modql/src/filter/nodes/node.rs`）：

`FilterNode` 的 `From` 实现只有**二元组**，不存在 `Equal` 类型：

```rust
impl From<(&str, &str)> for FilterNode      // name, value → OpValString::Eq
impl From<(&str, &String)> for FilterNode    // name, value → OpValString::Eq
impl From<(&str, String)> for FilterNode     // name, value → OpValString::Eq
```

**方案 §11.2 的错误写法**（2093/2122 行）：

```rust
let filters = vec![FilterNode::from(("username", Equal, &sa.username))];
let filters = vec![FilterNode::from(("code", Equal, "admin"))];
```

**修正建议**：改为二元组（隐式 `Eq`）：

```rust
let filters = vec![FilterNode::from(("username", sa.username.as_str()))];
let filters = vec![FilterNode::from(("code", "admin"))];
```

如需显式等值匹配或其他操作符：

```rust
use modql::filter::OpValString;
let filters = vec![FilterNode::from(("username", OpValString::Eq(sa.username.clone())))];
```

#### N22-b：`user.id` / `role.id` 字段访问语法不存在

**代码实测**（`crates/libs/cmx-core/src/model/data/dataset/rds.rs`）：

`Row` 的 `values` 字段可见性为 `pub(super)`，不支持 `row.field_name` 点号语法。**没有名为 `id` 的字段**。

**方案 §11.2 的错误写法**（2110/2130 行）：

```rust
Value::String(user.id.clone()),  // user 是 Option<&Row>，Row 无 id 字段
role_id: role.id                  // role 是 &Row，Row 无 id 字段
```

**修正建议**：使用 `Row::get_by_name_as` 方法（项目中已有广泛使用）：

```rust
let schema = dataset.schema.as_ref();

// 获取第一行
let row = dataset.iter().next();

// 访问字段
if let Some(row) = row {
    let user_id: String = row.get_by_name_as(schema, "id").unwrap_or_default();
    // 使用 user_id 而非 user.id
}

// role.id 同理
if let Some(role) = admin_role {
    let role_id: String = role.get_by_name_as(schema, "id").unwrap_or_default();
}
```

**完整修正后的 §11.2 `ensure_super_admin` 关键代码段**：

```rust
// 1. 查询用户是否已存在
let filters = vec![FilterNode::from(("username", sa.username.as_str()))];
let dataset = GenericCrudService::<UserBmc, UserFilter>::list(
    mm, db_id, None,
    Some(filters),
    Some(ListOptions::from_limit(1)),
).await?;
let schema = dataset.schema.as_ref();
let existing = dataset.iter().next();

// 2. 哈希密码
let password_hash = auth_service.hash_password(&sa.password).await?;

match existing {
    Some(row) => {
        let user_id: String = row.get_by_name_as(schema, "id").unwrap_or_default();
        let entity = UserUpdateEntity { password_hash: Some(password_hash), ... };
        GenericCrudService::<UserBmc>::update(
            mm, db_id, None,
            Value::String(user_id),
            entity,
        ).await?;
    }
    None => {
        let user_id = uuid::Uuid::new_v4().to_string();
        let entity = UserCreateEntity { id: user_id.clone(), ... };
        GenericCrudService::<UserBmc>::create(mm, db_id, None, entity).await?;

        // 查询 admin 角色
        let filters = vec![FilterNode::from(("code", "admin"))];
        let dataset = GenericCrudService::<RoleBmc, RoleFilter>::list(
            mm, db_id, None,
            Some(filters),
            Some(ListOptions::from_limit(1)),
        ).await?;
        let schema = dataset.schema.as_ref();
        if let Some(role_row) = dataset.iter().next() {
            let role_id: String = role_row.get_by_name_as(schema, "id").unwrap_or_default();
            let role_entity = UserRoleCreateEntity {
                id: uuid::Uuid::new_v4().to_string(),
                user_id,
                role_id,
            };
            GenericCrudService::<UserRoleBmc>::create(mm, db_id, None, role_entity).await?;
        }
    }
}
```
