# cmx-iam 权限完善方案 - 代码修改开发步骤

> 基于 [20260617_cmx-iam_权限完善优化方案.md](file:///media/yqs/工作/rustspace/cmx/cmx-container/.trae/documents/20260617_cmx-iam_权限完善优化方案.md) 制定，按 5 个阶段分迭代实施。

## 总体说明

### 开发原则

1. **每阶段独立交付**：每个阶段完成后通过 `cargo check` 和单元测试，确保不破坏现有功能
2. **遵循项目规范**：使用 `thiserror`、`tracing`、`workspace = true` 依赖引用方式
3. **代码风格一致**：参考 [role/service.rs](file:///media/yqs/工作/rustspace/cmx/cmx-container/crates/libs/cmx-iam/src/role/service.rs) 和 [user/service.rs](file:///media/yqs/工作/rustspace/cmx/cmx-container/crates/libs/cmx-iam/src/user/service.rs) 的事务模式、审计模式
4. **使用 rtk 加速编译验证**：`rtk cargo check`、`rtk cargo clippy`、`rtk cargo test`

### 文件路径约定

- 表迁移文件：`docs/sql/migrations/`
- cmx-iam 源码：`crates/libs/cmx-iam/src/`
- cmx-api handler：`crates/libs/cmx-api/src/handlers/iam/`
- 测试：`crates/libs/cmx-api/tests/`

### 依赖关系

```
阶段 1（临时角色） ──┬──> 阶段 2（SoD 规则）
                    └──> 阶段 3（缓存熔断）

阶段 4（审计 API） ── 依赖前 3 阶段
```
