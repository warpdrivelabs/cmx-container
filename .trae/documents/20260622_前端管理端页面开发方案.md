## 一、技术栈与整体规范

### 1.1 技术选型

| 类别      | 选型                                        | 说明                   |
| ------- | ----------------------------------------- | -------------------- |
| 框架      | Vue 3（Composition API + `<script setup>`） | 与现有 web-folder 技术栈一致 |
| UI 组件库  | Element Plus                              | 后台管理系统主流方案           |
| 路由      | Vue Router 4                              | 嵌套路由 + 路由守卫          |
| 状态管理    | Pinia                                     | 用户信息、权限码、侧边栏状态       |
| HTTP 请求 | Axios（封装统一拦截器）                            | 自动携带 Token、统一错误处理    |
| 构建工具    | Vite                                      | 快速开发体验               |

### 1.2 API 调用规范

| 规范       | 说明                                                      |
| -------- | ------------------------------------------------------- |
| Base URL | `/api`（开发环境通过 Vite proxy 代理到后端）                         |
| 认证头      | `Authorization: Bearer {access_token}`（Axios 请求拦截器自动注入） |
| 响应格式     | `{ code: 0, msg: "成功", data: T }`，code=0 为成功            |
| Token 刷新 | 响应拦截器捕获 401，自动调用 `/api/auth/refresh` 刷新后重试              |
| 分页参数     | `{ filter: {}, page: 1, size: 20 }`（POST body）          |
| 日期格式     | ISO 8601（`2026-06-22T10:00:00Z`），前端用 dayjs 格式化          |

### 1.3 权限控制规范

| 场景    | 实现方式                                                    |
| ----- | ------------------------------------------------------- |
| 路由级权限 | Vue Router `beforeEach` 守卫，检查 `meta.permissions` 与用户权限码 |
| 按钮级权限 | 自定义指令 `v-permission="'user:create'"`，无权限时隐藏按钮           |
| 菜单权限  | 根据用户权限码动态生成侧边栏菜单                                        |
| 超级管理员 | 拥有 `system:all` 权限码时显示全部菜单和按钮                           |

## 三、各页面详细设计

### P0. 登录页（`/login`）

**展示形式**：全屏居中卡片，左侧品牌展示区 + 右侧登录表单。

| UI 元素   | 组件       | 说明                                       |
| ------- | -------- | ---------------------------------------- |
| 用户名输入框  | ElInput  | 前缀图标 User，placeholder "请输入用户名"           |
| 密码输入框   | ElInput  | type=password，前缀图标 Lock，支持回车提交           |
| 设备类型选择  | ElSelect | 默认 "web"，选项 web/mobile/desktop           |
| 登录按钮    | ElButton | type=primary，全宽，loading 状态               |
| 第三方登录入口 | ElButton | Google/GitHub 图标按钮（条件渲染：先调 providers 接口） |

**功能与按钮**：

| 功能      | 触发             | 接口                                                                                                               |
| ------- | -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 登录      | 点击登录按钮         | `POST /api/auth/login` → 存储 access\_token/refresh\_token 到 localStorage                                          |
| 第三方登录入口 | 页面加载           | `GET /api/auth/oauth2/providers` → 条件渲染 Provider 按钮                                                              |
| 跳转第三方授权 | 点击 Provider 按钮 | `GET /api/auth/oauth2/provider/{provider}/authorize` → 窗口跳转                                                      |
| 第三方回调处理 | 回调页面           | `GET /api/auth/oauth2/{provider}/callback` → 获取一次性码 → `POST /api/auth/oauth2/provider/exchange` 换 Token |

**交互细节**：

* 登录失败显示 ElMessage.error，连续 5 次失败后显示锁定倒计时提示

* 登录成功后跳转到 `/dashboard` 或 redirect 参数指定的页面

* Token 存储在 localStorage（access\_token）+ localStorage（refresh\_token）

### P1. 个人中心（`/profile`）

**展示形式**：Tab 标签页切换，上部展示用户基本信息卡片。

| Tab   | 内容                             | 组件             |
| ----- | ------------------------------ | -------------- |
| 基本信息  | 头像、用户名、昵称、邮箱、手机、所属组织、最后登录时间/IP | ElDescriptions |
| 修改密码  | 旧密码、新密码、确认新密码 + 密码强度指示器        | ElForm         |
| 第三方账号 | 已绑定的 OAuth2 账号列表 + 绑定/解绑按钮     | ElTable        |

**功能与按钮**：

| 功能      | 按钮   | 接口                                                   | 权限     |
| ------- | ---- | ---------------------------------------------------- | ------ |
| 加载用户信息  | 页面加载 | `GET /api/auth/me`                                   | 登录用户自身 |
| 保存基本信息  | 保存修改 | `POST /api/iam/users/update`                         | 登录用户自身 |
| 修改密码    | 确认修改 | `POST /api/auth/change-password`                     | 登录用户自身 |
| 绑定第三方账号 | 绑定   | `POST /api/auth/oauth2/provider/{provider}/link`     | 登录用户自身 |
| 解绑第三方账号 | 解绑   | `DELETE /api/auth/oauth2/provider/{provider}/unlink` | 登录用户自身 |
| 退出登录    | 退出登录 | `POST /api/auth/logout`                              | 登录用户自身 |

**修改密码表单校验**：

* 旧密码：必填

* 新密码：最少 8 位，含大小写+数字+特殊字符（密码强度 ElProgress 实时展示）

* 确认密码：与新密码一致

### P2. 在线用户与会话管理（`/auth/sessions`）

**展示形式**：顶部统计卡片 + 下方操作区。

| 区域   | 展示内容               | 组件                   |
| ---- | ------------------ | -------------------- |
| 统计卡片 | 在线用户总数、今日登录数、活跃会话数 | ElCard + ElStatistic |
| 用户搜索 | 按用户名/用户ID搜索        | ElInput + ElButton   |
| 操作按钮 | 刷新列表、强制下线（批量）      | ElButton             |

**功能与按钮**：

| 功能        | 按钮         | 接口                                              | 权限                 |
| --------- | ---------- | ----------------------------------------------- | ------------------ |
| 强制下线（单用户） | 表格行内"强制下线" | `POST /api/auth/revoke-all`（body: { user\_id }) | `system:auth:kick` |
| 强制下线（批量）  | 表格顶部"批量下线" | `POST /api/auth/revoke-all`（循环或批量）              | `system:auth:kick` |

**表格列**：用户名、昵称、设备类型、登录时间、最后活跃时间、IP 地址、操作（强制下线）

> **注意**：当前后端无"查询在线用户列表"接口，仅有 `revoke-all` 强制下线接口。如需展示在线用户列表，需后端补充 `GET /api/auth/online-users` 接口（查询 Redis `auth:online:users` + session 详情）。此为前端依赖项，需与后端协调。

### P3. API Key 管理（`/auth/api-keys`）

**展示形式**：数据表格 + 新建抽屉。

**表格列**：

| 列名     | 说明                         |
| ------ | -------------------------- |
| Key 前缀 | 如 `cmx_inte`，用于展示识别    |
| 关联服务   | service\_name              |
| 关联用户   | user\_id（可空，服务级 Key 无用户）   |
| Scopes | 允许的权限范围（Tag 标签展示）          |
| 状态     | ElTag：启用(绿)/禁用(灰)          |
| 创建时间   | create\_time               |
| 操作     | 禁用/启用、删除                |

**功能与按钮**：

| 功能         | 按钮         | 展示形式            | 接口                                 | 权限           |
| ---------- | ---------- | --------------- | --------------------------------------- | ------------ |
| 新建 API Key | "新建" 按钮    | ElDrawer 右侧抽屉表单 | `POST /api/auth/api-keys/create`        | `system:all` |
| 查询列表       | 页面加载/筛选    | 表格数据           | `GET /api/auth/api-keys/list`           | `system:all` |
| 删除 API Key | 行内"删除"     | ElMessageBox 确认 | `POST /api/auth/api-keys/delete`        | `system:all` |
| 启用/禁用      | 行内开关       | ElSwitch        | `POST /api/auth/api-keys/toggle-status` | `system:all` |
| 复制 Key     | 仅创建后弹窗展示一次 | ElDialog + 复制按钮 | 创建接口返回明文 key                            | -            |

**新建表单字段**：关联服务名、关联用户（可选）、Scopes（多选 Tag）、描述

> **明文 Key 仅创建时展示一次**：创建成功后弹窗显示完整 key + "请立即复制保存，关闭后无法再次查看"警告。

### P4. OAuth2 客户端管理（`/auth/oauth2-clients`）

**展示形式**：数据表格 + 新建/编辑对话框。

**表格列**：

| 列名        | 说明                              |
| --------- | ------------------------------- |
| Client ID | 客户端标识                           |
| 客户端名称     | client\_name                    |
| 类型        | public/confidential（ElTag）      |
| 回调地址      | redirect\_uris（截断展示，hover 查看全部） |
| 授权类型      | grant\_types                    |
| PKCE      | 是否强制 PKCE（ElTag 是/否）            |
| 状态        | 启用/禁用                           |
| 操作        | 编辑、删除                           |

**功能与按钮**：

| 功能    | 按钮      | 展示形式            | 接口                                | 权限           |
| ----- | ------- | --------------- | -------------------------------------- | ------------ |
| 新建客户端 | "新建" 按钮 | ElDialog 全屏弹窗   | `POST /api/auth/oauth2-clients/create` | `system:all` |
| 查询列表  | 页面加载/筛选 | 表格数据           | `GET /api/auth/oauth2-clients/list`    | `system:all` |
| 编辑客户端 | 行内"编辑"  | ElDialog        | `POST /api/auth/oauth2-clients/update` | `system:all` |
| 删除客户端 | 行内"删除"  | ElMessageBox 确认 | `POST /api/auth/oauth2-clients/delete` | `system:all` |

**新建表单字段**：Client ID、客户端名称、Client Secret（confidential 类型）、类型（Radio: public/confidential）、回调地址（动态 Tag 输入）、授权类型（Checkbox）、允许 Scopes（Tag 输入）、是否强制 PKCE（Switch）、描述

> **编辑接口**：通过 `client_id` 定位记录，仅传需更新字段（留空不修改）。`client_secret` 传值则重置密钥。

| 临时授权 | 该用户的临时授权记录表格（含历史已过期/已撤销）                               | ElTable        | `GET /api/iam/users/temp-assignments?user_id=xxx`      |

### P7. 临时授权管理（`/iam/temp-assignments`）

**展示形式**：搜索筛选栏 + 数据表格 + 操作对话框。这是管理员视角的全局临时授权管理。

**搜索筛选栏**：

| 筛选项   | 组件               | 说明                   |
| ----- | ---------------- | -------------------- |
| 用户    | ElSelect（远程搜索用户） | 按 user\_id 筛选        |
| 角色    | ElSelect（远程搜索角色） | 按 role\_id 筛选        |
| 状态    | ElSelect         | 全部 / 生效中 / 已过期 / 已撤销 |
| 搜索/重置 | ElButton         | -                    |

**表格列**：

| 列名   | 说明                 | 特殊展示                       |
| ---- | ------------------ | -------------------------- |
| 用户   | username（nickname） | -                          |
| 角色   | role code（name）    | -                          |
| 生效时间 | effective\_from    | -                          |
| 过期时间 | effective\_until   | 临近过期(7天内)显示橙色 Tag          |
| 授权来源 | source             | manual/approval/system     |
| 状态   | status             | ElTag：生效中(绿)/已过期(灰)/已撤销(红) |
| 授权理由 | reason             | tooltip 展示                 |

## 五、前端路由守卫设计

### 5.1 路由元信息

```javascript

  path: '/iam/users',
  meta: {
    title: '用户管理',

    breadcrumb: ['管理后台', '用户管理', '用户列表']
  }
}
```

### 5.2 守卫逻辑

| 步骤                                   | 说明                                            |
| ------------------------------------ | --------------------------------------------- |
| 1. 检查 localStorage 是否有 access\_token | 无 → 跳转 `/login`                               |
| 2. 检查 token 是否即将过期                   | 是 → 调用 `POST /api/auth/refresh` 刷新            |
| 3. 检查用户权限码（Pinia store）              | 未加载 → 从 JWT payload 解析或调 `/api/auth/validate` |
| 4. 检查路由 meta.permissions             | 有 system:all → 放行；否则逐一匹配                      |
| 5. 设置页面标题                            | document.title = meta.title                   |

| 优先级         | 页面                                                  | 理由              |
| ----------- | --------------------------------------------------- | --------------- |
| **P0（必须有）** | 登录页(P0) + 用户列表(P5) + 角色列表(P8) + 权限列表(P10)           | 核心 CRUD，系统可用性基础 |
| **P1（重要）**  | 个人中心(P1) + 用户详情(P6) + 角色详情(P9) + 分配角色/权限弹窗          | 完整的用户体验闭环       |
| **P2（增强）**  | 临时授权管理(P7) + 权限规则管理(P12)                   | 高级功能，企业级场景      |
| **P3（可选）**  | 在线用户(P2) + API Key(P3) + OAuth2 客户端(P4) + 权限统计(P11) | 运维功能，在线用户列表需后端补充接口 |

## 八、假设与决策

| 决策                         | 理由                                                |
| -------------------------- | ------------------------------------------------- |
| 技术栈选择 Vue 3 + Element Plus | 与现有 web-folder Vue 技术栈一致，Element Plus 是后台管理系统主流方案 |
| 使用 Pinia 而非 Vuex           | Vue 3 官方推荐的状态管理方案，TypeScript 支持更好                 |
| Token 存储在 localStorage     | 前端 SPA 场景，避免 Cookie 的 CSRF 风险                     |
| 分配角色使用 Transfer 穿梭框        | 直观的未分配/已分配两栏对比，批量操作友好                             |
| 分配权限使用 Tree 树形复选框          | 权限有父子层级，树形展示比扁平列表更直观                              |
| 角色列表使用扁平表格                | 角色保持扁平模型，不使用树形/层级展示                              |
| 权限规则项使用动态表单                | 互斥规则需配置主对象和互斥对象列表                              |
| 需后端补充 1 类接口                | 在线用户列表查询（API Key 和 OAuth2 客户端 CRUD 已实现）             |
| 页面权限码与后端权限码对齐              | 直接使用后端定义的 resource:action 格式（如 `user:create`）     |
| 个人中心支持第三方账号绑定/解绑           | OAuth2 Provider 的 link/unlink 接口                  |
