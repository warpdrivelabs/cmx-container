# 插件生命周期管理与版本控制系统架构文档

## 一、设计背景与关键需求

### 1.1 多数据库架构背景

本系统采用**多数据库架构**，这是本方案的核心设计特点：

* **默认数据库 (Default Database)**: 系统默认的主数据库，用于存储插件元数据、版本历史、部署记录等核心管理信息。每个数据库通过 `db_id` 进行唯一标识。

* **插件独立数据库 (Plugin Databases)**: 插件可以拥有自己的数据库（通过 `db_id` 指定），用于存储插件自身的业务数据表，实现数据隔离。

### 1.2 设计目标

本架构文档旨在重建并优化 cmx-plugin 的插件生命周期管理系统，提供一套完整的解决方案来管理插件的安装、卸载、激活/停用、升级和降级流程，以及版本管理系统。该系统需要满足以下关键要求：

1. **多数据库支持** - 插件元数据存储在默认数据库，插件业务数据可存储在指定数据库
2. **多节点部署策略** - 支持在多个节点之间同步安装插件
3. **系统默认插件初始化** - 应用程序启动时自动安装默认插件
4. **数据库架构设计** - 完整的表结构支持插件生命周期管理
5. **版本管理架构** - 语义版本控制、版本约束、兼容性检查、回滚功能
6. **错误处理与恢复** - 事务回滚机制和恢复流程
7. **依赖管理** - 依赖解析、循环依赖检测、版本兼容性
8. **激活/停用工作流程** - 资源分配/释放、服务注册/注销
9. **审计与日志记录** - 全面的生命周期事件记录
10. **安全考量** - 完整性验证、权限检查、资源隔离
11. **性能优化** - 高并发、高可用环境下的性能保障

### 1.3 核心概念定义

| 概念                                | 定义                                      |
| --------------------------------- | --------------------------------------- |
| **db\_id**                        | 数据库唯一标识符，用于在 cmx-database 中标识和连接特定数据库   |
| **默认数据库 (Default DB)**            | 系统默认主数据库，存储插件元数据表（cmx\_plugin 等），通过配置获取 |
| **插件数据库 (Plugin DB)**             | 插件自己的数据库，用于存储插件的业务数据表，创建时指定             |
| **插件 (Plugin)**                   | 由 WASM 二进制文件和元数据组成的可扩展功能单元              |
| **插件定义 (PluginDefinition)**       | 描述插件属性（ID、名称、版本、依赖等）的 JSON 结构           |
| **装配清单 (PluginManifest)**         | ZIP 包内的 manifest.json，描述插件包内容           |
| **插件注册表 (PluginRegistry)**        | 内存中存储已加载插件信息的组件                         |
| **插件管理器 (PluginManager)**         | 负责插件生命周期操作的核心组件，使用 cmx-database 进行数据库操作 |
| **版本管理器 (VersionManager)**        | 管理插件版本、控制升级/降级的组件                       |
| **依赖解析器 (DependencyResolver)**    | 解析和验证插件依赖关系的组件                          |
| **部署协调器 (DeploymentCoordinator)** | 协调多节点插件部署的组件                            |
| **激活管理器 (ActivationManager)**     | 管理插件激活/停用状态的组件                          |

### 2.2 核心组件说明

#### 2.2.1 插件管理器 (PluginManager)

```rust
/// 插件管理器 - 负责插件完整生命周期操作
pub struct PluginManager {
    /// 数据库管理器（用于操作默认数据库的插件元数据表）
    db_manager: Arc<DatabaseManager>,
    /// 默认数据库ID
    default_db_id: String,
    /// 内存注册表
    registry: Arc<RwLock<PluginRegistry>>,
    /// 版本管理器
    version_manager: Arc<VersionManager>,
    /// 依赖解析器
    dependency_resolver: Arc<DependencyResolver>,
    /// 部署协调器
    deployment_coordinator: Arc<DeploymentCoordinator>,
    /// 激活管理器
    activation_manager: Arc<ActivationManager>,
    /// 审计日志
    audit_logger: Arc<AuditLogger>,
    /// 安全验证器
    security_validator: Arc<SecurityValidator>,
}

impl PluginManager {
    /// 安装插件
    /// 流程: 验证 -> 解析依赖 -> 校验版本 -> 创建备份 -> 执行安装 -> 在指定数据库创建表 -> 更新元数据状态 -> 记录日志
    /// 
    /// # 参数说明
    /// - `request`: 安装请求，包含插件来源和目标数据库配置
    /// - `default_db_id`: 默认数据库ID，用于存储插件元数据表
    pub async fn install(&self, request: &InstallRequest) -> Result<InstallResult, PluginError>;
    
    /// 卸载插件
    /// 流程: 检查依赖 -> 停用插件 -> 删除文件 -> 清理数据（默认DB + 插件DB）-> 更新状态 -> 记录日志
    pub async fn uninstall(&self, plugin_id: &str, force: bool) -> Result<(), PluginError>;
    
    /// 升级插件
    /// 流程: 验证新版本 -> 检查兼容性 -> 创建回滚点 -> 执行升级 -> 迁移表结构 -> 验证 -> 更新状态
    pub async fn upgrade(&self, plugin_id: &str, new_version: &str) -> Result<UpgradeResult, PluginError>;
    
    /// 降级插件
    pub async fn downgrade(&self, plugin_id: &str, target_version: &str) -> Result<DowngradeResult, PluginError>;
    
    /// 回滚操作
    pub async fn rollback(&self, operation_id: &str) -> Result<RollbackResult, PluginError>;
    
    /// 获取插件关联的数据库ID
    pub async fn get_plugin_db_id(&self, plugin_id: &str) -> Result<String, PluginError>;
}
```

## 三、数据库架构设计

### 3.1 多数据库架构概述

本系统采用**双数据库存储模式**：

1. **默认数据库 (Default Database)**

   * 存储插件元数据、版本历史、依赖关系、部署记录、审计日志等核心管理信息

   * 通过 `db_id` 在 cmx-database 中标识

   * 插件管理表（cmx\_plugin 等）位于此数据库

2. **插件独立数据库 (Plugin Database)**

   * 存储插件自身的业务数据表（由插件的 table\_config\_files 定义）

   * 每个插件可指定不同的 `db_id`，实现数据隔离

   * 使用 cmx-metadata 模块创建和管理这些表

### 4.1 插件安装流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           插件安装流程                                         │
│                    (支持本地路径/URL/注册表/目录)                             │

开始 ──┐
       │
       ▼

│ 1. 接收安装请求   │  接收来源类型、目标数据库和节点列表

impl DependencyResolver {
    /// 检测循环依赖 (使用 DFS)
    pub fn detect_cycles(&self, graph: &DependencyGraph) -> Vec<Vec<String>> {
        let mut visited: HashSet<String> = HashSet::new();
        let mut rec_stack: HashSet<String> = HashSet::new();
        let mut cycles: Vec<Vec<String>> = Vec::new();
        
        for node in &graph.nodes {
            if !visited.contains(&node.plugin_id) {
                self.detect_cycle_dfs(
                    &node.plugin_id,
                    graph,
                    &mut visited,
                    &mut rec_stack,
                    &mut Vec::new(),
                    &mut cycles,
                );
            }
        }
        cycles
    }
    
    fn detect_cycle_dfs(
        &self,
        plugin_id: &str,
        graph: &DependencyGraph,
        visited: &mut HashSet<String>,
        rec_stack: &mut HashSet<String>,
        path: &mut Vec<String>,
        cycles: &mut Vec<Vec<String>>,
    ) {
        visited.insert(plugin_id.to_string());
        rec_stack.insert(plugin_id.to_string());
        path.push(plugin_id.to_string());
        
        for edge in &graph.edges {
            if edge.from == plugin_id {
                let dep_id = &edge.to;
                if !visited.contains(dep_id) {
                    self.detect_cycle_dfs(dep_id, graph, visited, rec_stack, path, cycles);
                } else if rec_stack.contains(dep_id) {
                    // 发现循环
                    if let Some(pos) = path.iter().position(|p| p == dep_id) {
                        cycles.push(path[pos..].to_vec());
                    }
                }
            }
        }
        
        path.pop();
        rec_stack.remove(plugin_id);
    }
}

    /// 开启安装事务
    pub async fn begin_install_transaction(

        // 1. 获取数据库连接

    /// 回滚事务
    pub async fn rollback(&self, tx: &mut InstallTransaction) -> Result<(), PluginError> {
        // 1. 按逆序执行回滚操作
        for action in tx.rollback_actions.drain(..).rev() {
            action.execute().await?;
        }
        
        // 2. 回滚数据库事务
        tx.conn.rollback().await?;
        
        // 3. 更新事务状态
        self.update_transaction_status(tx.tx_id, TxStatus::RolledBack).await?;
        
        Ok(())
    }
    
    /// 提交事务
    pub async fn commit(&self, tx: &mut InstallTransaction) -> Result<(), PluginError> {
        tx.conn.commit().await?;
        self.update_transaction_status(tx.tx_id, TxStatus::Committed).await?;
        Ok(())
    }

/// 插件源获取器 - 根据来源类型获取插件包
pub struct PluginSourceFetcher {
    http_client: reqwest::Client,
    temp_dir: PathBuf,
}

impl PluginSourceFetcher {
    /// 根据来源类型获取插件包，返回临时目录路径
    pub async fn fetch(&self, source: &PluginSource) -> Result<PathBuf, PluginError> {
        match source {
            PluginSource::Zip { path } => {
                // 本地 ZIP 文件：直接使用
                self.fetch_from_local(path).await
            }
            PluginSource::Url { url, headers } => {
                // URL 下载：支持 HTTP/HTTPS
                self.fetch_from_url(url, headers).await
            }
            PluginSource::Registry { plugin_id, version } => {
                // 从注册表获取
                self.fetch_from_registry(plugin_id, version.as_deref()).await
            }
            PluginSource::Directory { path } => {
                // 已解压目录：打包成临时 ZIP
                self.fetch_from_directory(path).await
            }
        }
    }
    
    /// 从本地路径获取
    async fn fetch_from_local(&self, path: &str) -> Result<PathBuf, PluginError> {
        let path = Path::new(path);
        if !path.exists() {
            return Err(PluginError::Install(format!("文件不存在: {}", path.display())));
        }
        // 返回父目录作为临时目录
        Ok(path.parent().unwrap_or(path).to_path_buf())
    }
    
    /// 从 URL 下载
    async fn fetch_from_url(
        &self, 
        url: &str, 
        headers: &HashMap<String, String>
    ) -> Result<PathBuf, PluginError> {
        // 验证 URL
        let parsed_url = url::Url::parse(url)
            .map_err(|e| PluginError::Install(format!("无效的 URL: {}", e)))?;
        
        if !matches!(parsed_url.scheme(), "http" | "https") {
            return Err(PluginError::Install("仅支持 HTTP/HTTPS 协议".to_string()));
        }
        
        // 构建请求
        let mut request = self.http_client.get(url);
        for (key, value) in headers {
            request = request.header(key, value);
        }
        
        // 下载文件
        let response = request.send().await
            .map_err(|e| PluginError::Install(format!("下载失败: {}", e)))?;
        
        if !response.status().is_success() {
            return Err(PluginError::Install(format!(
                "下载失败，HTTP状态码: {}", response.status()
            )));
        }
        
        // 保存到临时文件
        let temp_file = self.temp_dir.join("download.zip");
        let bytes = response.bytes().await
            .map_err(|e| PluginError::Install(format!("读取响应失败: {}", e)))?;
        
        tokio::fs::write(&temp_file, &bytes).await
            .map_err(|e| PluginError::Io(e))?;
        
        // 解压到临时目录
        let temp_extract_dir = self.temp_dir.join("extracted");
        self.extract_zip(&temp_file, &temp_extract_dir).await?;
        
        Ok(temp_extract_dir)
    }
    
    /// 从注册表获取
    async fn fetch_from_registry(
        &self, 
        plugin_id: &str, 
        version: Option<&str>
    ) -> Result<PathBuf, PluginError> {
        // TODO: 实现从插件注册表获取的逻辑
        // 1. 查询注册表获取插件信息
        // 2. 获取下载 URL
        // 3. 下载并解压
        Err(PluginError::Install("注册表功能尚未实现".to_string()))
    }
    
    /// 从目录获取（打包成 ZIP）
    async fn fetch_from_directory(&self, path: &str) -> Result<PathBuf, PluginError> {
        let dir_path = Path::new(path);
        if !dir_path.exists() || !dir_path.is_dir() {
            return Err(PluginError::Install(format!("目录不存在: {}", path)));
        }
        
        // 验证目录中是否存在 manifest.json
        let manifest_path = dir_path.join("manifest.json");
        if !manifest_path.exists() {
            return Err(PluginError::Install("目录中不存在 manifest.json".to_string()));
        }
        
        // 返回目录路径（已解压）
        Ok(dir_path.to_path_buf())
    }
    
    /// 解压 ZIP 文件
    async fn extract_zip(&self, zip_path: &Path, dest_dir: &Path) -> Result<(), PluginError> {
        let file = std::fs::File::open(zip_path)
            .map_err(|e| PluginError::Io(e))?;
        let mut archive = zip::ZipArchive::new(file)
            .map_err(|e| PluginError::Zip(e.to_string()))?;
        
        std::fs::create_dir_all(dest_dir)
            .map_err(|e| PluginError::Io(e))?;
        
        archive.extract(dest_dir)
            .map_err(|e| PluginError::Zip(e.to_string()))?;
        
        Ok(())
    }
}

let dataset = query_sql_by_ids(
    db_id,
    txn_id,
    "SELECT * FROM users WHERE id = ?",
    "dataset_id"
).await?;
```

#### 11.3.2 表定义配置管理器（依赖解析复用）

使用 `cmx-metadata` 的 `TableDefinesConfigManager::sorted_configs()` 进行 BFS 拓扑排序，确保依赖表被正确创建：

```rust
use cmx_metadata::config::TableDefinesConfigManager;

let config_manager = TableDefinesConfigManager::from_config_paths(&config_paths)?;

// BFS 拓扑排序：按依赖顺序返回表配置
// 确保被依赖的表先创建，依赖的表后创建
let sorted_table_configs = config_manager.sorted_configs();

for table_config in sorted_table_configs {
    // 按正确顺序创建/升级表
    executor.create_or_upgrade_table(table_config, db_id).await?;
}
```

#### 11.3.3 插件业务表创建/升级

使用 `cmx-metadata` 的 `TableDefineExecutor::create_or_upgrade_table()` 在指定数据库上创建或升级表：

use cmx_metadata::executor::TableDefineExecutor;

### 11.4 架构要点总结

1. **双数据库分离**

   * 插件系统表（如 `cmx_plugin`, `cmx_plugin_versions` 等）在**默认数据库**（`default_db_id`）

   * 插件业务数据表通过 `metadata_db_id` 参数指向**任意已注册数据库**

2. **ZIP 来源多态**

   * `PluginSource` 枚举统一处理本地路径和 HTTP/HTTPS URL

   * URL 来源自动下载到临时目录后再处理

3. **数据库操作统一**

   * 所有 DB 操作通过 `cmx-database` 库的 `execute_sql_by_ids` / `query_sql_by_ids` + `db_id`/`txn_id` 模式

   * 元数据升级通过 `cmx-metadata` 模块的 `TableDefineExecutor`

#### 11.5.2 启动流程实现 (`init.rs`)

```rust
use serde::Deserialize;
use tokio::fs;

/// 默认插件配置
#[derive(Debug, Deserialize)]
pub struct DefaultPluginsConfig {
    #[serde(default)]
    pub settings: SettingsConfig,
    #[serde(default = "Vec::new")]
    pub required: Vec<PluginConfig>,
    #[serde(default = "Vec::new")]
    pub optional: Vec<PluginConfig>,
}

#[derive(Debug, Deserialize)]
pub struct SettingsConfig {
    #[serde(default = "default_install_root")]
    pub install_root: String,
    #[serde(default = "default_temp_dir")]
    pub temp_dir: String,
    #[serde(default = "default_db_id")]
    pub default_db_id: String,
}

#[derive(Debug, Deserialize)]
pub struct PluginConfig {
    pub id: String,
    pub version: String,
    pub source: String,
    #[serde(default)]
    pub metadata_db_id: Option<String>,
}

/// 插件初始化器
pub struct PluginInitializer {
    config: DefaultPluginsConfig,
    plugin_manager: Arc<PluginManager>,
}

impl PluginInitializer {
    /// 从配置文件加载
    pub async fn from_file(path: &str) -> Result<Self, PluginError> {
        let content = fs::read_to_string(path).await
            .map_err(|e| PluginError::Config(format!("读取配置文件失败: {}", e)))?;
        
        let config: DefaultPluginsConfig = toml::from_str(&content)
            .map_err(|e| PluginError::Config(format!("解析配置文件失败: {}", e)))?;
        
        Ok(Self {
            config,
            plugin_manager: Arc::new(PluginManager::new()?),
        })
    }
    
    /// 执行系统启动时的插件初始化
    pub async fn initialize(&self) -> Result<InitResult, PluginError> {
        // 1. 确保插件系统表存在
        self.ensure_schema().await?;
        
        let mut results = InitResult::default();
        
        // 2. 处理必需插件（失败则阻断启动）
        for plugin_config in &self.config.required {
            match self.install_or_upgrade(plugin_config).await {
                Ok(_) => results.required_succeeded += 1,
                Err(e) => {
                    results.required_failed += 1;
                    results.critical_errors.push(format!(
                        "必需插件 [{}] 安装失败: {}",
                        plugin_config.id, e
                    ));
                    // 必需插件失败，阻断启动
                    return Err(PluginError::Init(format!(
                        "系统启动被必需插件 [{}] 的安装失败阻断",
                        plugin_config.id
                    )));
                }
            }
        }
        
        // 3. 处理可选插件（失败仅记录警告）
        for plugin_config in &self.config.optional {
            match self.install_or_upgrade(plugin_config).await {
                Ok(_) => results.optional_succeeded += 1,
                Err(e) => {
                    results.optional_failed += 1;
                    results.warnings.push(format!(
                        "可选插件 [{}] 安装失败: {}（系统将继续启动）",
                        plugin_config.id, e
                    ));
                }
            }
        }
        
        Ok(results)
    }
    
    /// 确保插件系统表存在
    async fn ensure_schema(&self) -> Result<(), PluginError> {
        let db_id = &self.config.settings.default_db_id;
        
        // 创建插件系统表（如果不存在）
        // 注意：使用 cmx-metadata 或直接执行 DDL
        let schema_sqls = vec![
            "CREATE TABLE IF NOT EXISTS cmx_plugin (...)",
            "CREATE TABLE IF NOT EXISTS cmx_plugin_versions (...)",
            // ... 其他系统表
        ];
        
        for sql in schema_sqls {
            execute_sql_by_ids(db_id, None, sql).await?;
        }
        
        Ok(())
    }
    
    /// 安装或升级插件
    async fn install_or_upgrade(&self, config: &PluginConfig) -> Result<(), PluginError> {
        let db_id = &self.config.settings.default_db_id;
        let metadata_db_id = config.metadata_db_id.as_deref().unwrap_or(db_id);
        
        // 检查是否已安装
        let existing = query_sql_by_ids(
            db_id,
            None,
            &format!("SELECT version FROM cmx_plugin WHERE plugin_id = '{}'", config.id),
            "check_existing"
        ).await?;
        
        if let Some(row) = existing.rows.first() {
            // 已安装，检查版本
            let current_version = row.get("version");
            if satisfies_version(&current_version, &config.version) {
                // 版本满足要求，跳过
                return Ok(());
            } else {
                // 版本不满足，需要升级
                self.plugin_manager.upgrade(&config.id, &config.version).await?;
            }
        } else {
            // 未安装，执行安装
            let source = if config.source.starts_with("http://") || config.source.starts_with("https://") {
                PluginSource::Url { 
                    url: config.source.clone(), 
                    headers: HashMap::new() 
                }
            } else {
                PluginSource::Zip { path: config.source.clone() }
            };
            
            let request = InstallRequest {
                plugin_id: Some(config.id.clone()),
                source,
                target_db_id: Some(metadata_db_id.to_string()),
                target_db_type: None,
                target_nodes: None,
                config: None,
                force: false,
                skip_validation: false,
                operator: "system".to_string(),
            };
            
            self.plugin_manager.install(&request).await?;
        }
        
        Ok(())
    }
}

/// 初始化结果
#[derive(Debug, Default)]
pub struct InitResult {
    pub required_succeeded: usize,
    pub required_failed: usize,
    pub optional_succeeded: usize,
    pub optional_failed: usize,
    pub critical_errors: Vec<String>,
    pub warnings: Vec<String>,
}
```
