# 服务定义扩展与分页查询功能实现计划

## 背景

`cmx_service_define` 表新增了 `domain_code`、`application_code`、`module_code` 字段，需要：
1. 在插件安装/卸载时保存这几个字段
2. 新增 `page_services` 分页查询接口，支持多条件查询

## 涉及模块

- `cmx-core`: 数据模型扩展
- `cmx-traits`: 接口定义
- `cmx-service`: 接口实现
- `cmx-plugin`: 服务解析与保存
- `cmx-api`: HTTP 接口

---

## 实现步骤

### 1. cmx-core 数据模型扩展

**文件**: `crates/libs/cmx-core/src/model/service/definition.rs`

- `ServiceDefinition` 结构体新增字段：
  - `domain_code: String`
  - `application_code: String`
  - `module_code: String`

- `ServiceInfo` 结构体新增字段：
  - `domain_code: String`
  - `application_code: String`
  - `module_code: String`

- 更新 `From<ServiceDefinition> for ServiceInfo` 实现

**文件**: `crates/libs/cmx-core/src/model/service/orchestration.rs`

- `ServiceOrchestration` 结构体新增字段：
  - `domain_code: Option<String>` (可选，兼容旧数据)
  - `application_code: Option<String>`
  - `module_code: Option<String>`

---

### 2. cmx-traits 接口定义

**文件**: `crates/libs/cmx-traits/src/service_query.rs`

新增 `ServicePageFilter` 结构体和 `page_services` 方法：

```rust
/// 服务分页查询过滤器
pub struct ServicePageFilter {
    /// 服务 key 模糊查询
    pub service_key: Option<String>,
    /// 服务名称模糊查询
    pub service_name: Option<String>,
    /// 插件 ID 精确匹配
    pub plugin_id: Option<String>,
    /// 域代码精确匹配
    pub domain_code: Option<String>,
    /// 应用代码精确匹配
    pub application_code: Option<String>,
    /// 模块代码精确匹配
    pub module_code: Option<String>,
}

/// 服务分页结果
pub struct ServicePageResult {
    pub items: Vec<ServiceInfo>,
    pub total: u64,
}

// ServiceQuery trait 新增方法
async fn page_services(
    &self,
    filter: ServicePageFilter,
    page: u64,
    size: u64,
) -> Result<ServicePageResult, TraitError>;
```
