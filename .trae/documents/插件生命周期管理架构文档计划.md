# 插件生命周期管理与版本控制系统架构文档重建计划

## 一、计划概述

基于对 cmx-plugin 现有代码的分析（README.md 和 manifest\_example.json），以及用户反馈的多数据库架构需求，制定本计划以创建全面的插件生命周期管理架构文档。

### 1.1 现有代码分析结果

**现有架构**:

* 插件定义：单文件 JSON 或 ZIP 包内 manifest.json

* 签名验证：Ed25519 非对称签名

* 表配置管理：通过 table\_config\_files 关联建表配置

* 插件注册表：内存中存储插件元数据

**用户新增需求**:

* 插件元数据存储在默认数据库

* 插件自身的数据表可以存储在指定的数据库（通过 db\_id 指定）

* 使用 cmx-database 库进行数据库操作

* 使用 cmx-metadata 模块进行表结构升级

* 支持多种插件来源：本地路径、URL、注册表、目录

### 1.2 计划执行步骤

1. **分析现有代码** - 已完成
2. **创建架构文档框架** - 已完成
3. **更新组件架构设计（加入 db\_id 支持）** - 已完成
4. **更新数据库设计（添加 cmx\_plugin\_db 表）** - 已完成
5. **更新流程图和 API 规范** - 已完成
6. **编写实施指南（cmx-database 和 cmx-metadata 集成）** - 已完成
