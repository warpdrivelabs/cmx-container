# 配置同步技能

当新增或修改配置项时，必须同步更新对应的文件。配置分为两类：

1. **TOML 配置** — 通过配置文件（`dev.toml` / `config.toml`）管理的配置项
2. **环境变量配置** — 仅通过环境变量注入的配置项（如注册中心、配置中心等敏感信息）

---

## 一、文件结构

| 文件 | 类型 | 说明 |
|------|------|------|
| `config/config_template.toml` | TOML 配置模板 | TOML 配置项的完整模板和默认值 |
| `config/.env.template` | 环境变量参考模板 | 环境变量以 `.env` 格式列出 |
| `config/CONFIG_MANUAL.md` | TOML 配置手册 | TOML 配置项的详细文档 |
| `config/ENV_MANUAL.md` | 环境变量手册 | 环境变量的详细文档 |

### 分离原则

- **TOML 配置**: 可以在 `.toml` 配置文件中设置的项 → 放入 `config_template.toml` + `CONFIG_MANUAL.md`
- **环境变量配置**: 仅通过环境变量注入、不在 TOML 文件中配置的项 → 放入 `env_template.toml` + `ENV_MANUAL.md`
- **TOML 配置的环境变量覆盖**: TOML 配置项支持的环境变量覆盖方式，在 `CONFIG_MANUAL.md` 对应章节末尾说明

---

## 二、触发条件

当用户执行以下操作时，**必须**触发此技能：

- 新增或修改 TOML 配置项 → 更新 `config_template.toml` + `CONFIG_MANUAL.md`
- 新增或修改环境变量 → 更新 `.env.template` + `ENV_MANUAL.md`
- 删除配置项或环境变量 → 同步更新对应文件
- 用户明确要求"更新配置文档"、"同步配置"等

---

## 三、操作步骤

### 步骤 1：确定配置类型

判断新增/修改的配置属于哪一类：
- 如果配置可以在 `.toml` 文件中设置 → **TOML 配置**
- 如果配置仅通过环境变量注入 → **环境变量配置**

### 步骤 2：更新模板文件

#### TOML 配置模板 (`config/config_template.toml`)

```toml
# ============================================
# <配置节中文名称>
# ============================================
[<section_name>]
# 配置项说明（可选/必需，默认 <默认值>）
key = "default_value"
```

- 每个配置节上方添加分隔注释 `# ============================================`
- 每个配置项上方添加中文注释说明
- 注释中标注：是否可选、默认值、用途说明
- 可选配置项以注释形式呈现（行首加 `#`）
- 必需配置项直接写值

#### 环境变量参考模板 (`config/.env.template`)

```bash
# ============================================
# <分类中文名称>（通过环境变量注入）
# ============================================
# 说明文字

# 变量说明（默认值、用途）
VARIABLE_NAME=default_value
# 变量说明（留空使用内置默认）
OPTIONAL_VAR=
```

- `.env` 文件格式，`#` 开头为注释
- **每个变量上方必须有注释说明**：标注默认值、用途、是否可选
- 变量名用大写，`=` 后跟默认值
- 留空表示使用代码内置默认值
- 不推荐使用的旧变量以注释形式呈现（行首加 `#`），并在注释中说明"不推荐"和对应新变量

### 步骤 3：更新手册文件

#### TOML 配置手册 (`config/CONFIG_MANUAL.md`)

```markdown
## <配置节中文名称>

### `[<section_name>]`

#### `<key>`

- **类型**: <类型>
- **必需**: 是/否
- **默认值**: `<默认值>`
- **说明**: <详细说明>
- **示例**: `<示例值>`
```

- 同时更新目录中的条目
- 保持与现有文档风格一致
- 如支持环境变量覆盖，在章节末尾说明格式

#### 环境变量手册 (`config/ENV_MANUAL.md`)

```markdown
## <分类中文名称>

### VARIABLE_NAME

- **类型**: <类型>
- **默认值**: `<默认值>`
- **说明**: <详细说明>
- **示例**: `<示例值>`
```

- 同时更新目录中的条目
- 包含优先级说明和兼容旧变量映射
- 旧变量标注"不推荐"

---

## 四、注意事项

1. **分类准确**: TOML 配置和环境变量配置不要混放
2. **同时更新模板和手册**: 模板文件和手册文件必须同步更新
3. **保持目录完整**: 两个手册文件的目录中需同步添加/修改条目
4. **注释风格一致**: 遵循现有文件的注释风格
5. **不要删除已有内容**: 只追加或修改对应部分
6. **交叉引用**: 如果 TOML 配置项支持环境变量覆盖，在 `CONFIG_MANUAL.md` 中注明"详见 [ENV_MANUAL.md](ENV_MANUAL.md)"

---

## 五、验证

更新完成后，检查：

- [ ] TOML 配置项 → `config_template.toml` 和 `CONFIG_MANUAL.md` 已同步
- [ ] 环境变量 → `.env.template` 和 `ENV_MANUAL.md` 已同步
- [ ] 两个手册文件的目录已更新
- [ ] 所有字段类型、默认值、说明准确无误
- [ ] 不推荐使用的旧变量已标注
- [ ] `.env.template` 中每个变量上方都有注释说明
