# 配置同步技能

当新增或修改 `dev.toml` 中的配置项时，必须同步更新以下两个文件：

1. **配置模板文件**: `config/config_template.toml`
2. **配置手册文件**: `config/CONFIG_MANUAL.md`

---

## 一、触发条件

当用户执行以下操作时，**必须**触发此技能：

- 在 `dev.toml` 中新增了配置节或配置项
- 修改了 `dev.toml` 中已有配置项的含义、默认值、类型等
- 删除了 `dev.toml` 中的配置项
- 用户明确要求"更新配置文档"、"同步配置"等

---

## 二、操作步骤

### 步骤 1：更新 `config/config_template.toml`

在配置模板文件中对应位置添加新的配置节和配置项，格式要求：

```toml
# ============================================
# <配置节中文名称>
# ============================================
[<section_name>]
# 配置项说明（可选/必需，默认 <默认值>）
key = "default_value"
```

- 每个配置节上方添加分隔注释 `# ============================================`
- 每个配置项上方添加中文注释说明
- 注释中标注：是否可选、默认值、用途说明
- 可选配置项以注释形式呈现（行首加 `#`）
- 必需配置项直接写值

### 步骤 2：更新 `config/CONFIG_MANUAL.md`

在配置手册中添加对应的配置项文档，格式要求：

```markdown
## <配置节中文名称>

### `[<section_name>]`

#### `<key>`

- **类型**: <类型>
- **必需**: 是/否
- **默认值**: `<默认值>`
- **说明**: <详细说明>
- **示例**: `<示例值>`
```

- 同时更新目录（Table of Contents）中的条目
- 保持与现有文档风格一致
- 环境变量覆盖需单独说明

---

## 三、注意事项

1. **同时更新两个文件**：模板和手册必须同步更新，不能遗漏
2. **保持文档目录完整**：CONFIG_MANUAL.md 的目录中需添加新条目
3. **注释风格一致**：遵循现有 config_template.toml 的注释风格
4. **环境变量说明**：如果配置项支持环境变量覆盖，在 CONFIG_MANUAL.md 中说明格式
5. **不要删除已有内容**：只追加或修改对应部分

---

## 四、验证

更新完成后，检查：

- [ ] config_template.toml 中新增配置节/项格式正确
- [ ] CONFIG_MANUAL.md 目录已更新
- [ ] CONFIG_MANUAL.md 中新增章节格式与现有章节一致
- [ ] 所有字段类型、默认值、说明准确无误
