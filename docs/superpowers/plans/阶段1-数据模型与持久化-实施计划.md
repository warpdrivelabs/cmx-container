# 阶段1:数据模型与持久化 — 逐步实施计划

> **配套方案:** `docs/superpowers/plans/20260630_cmx-plugin_模块为中心的插件解耦与迁移包方案.md`
> **分支:** `feat/module-centric-restructure`
> **目标:** 完成 cmx_form / cmx_menu / 模块版本两表的 SQL 迁移 + Rust 模型 + BMC + Service,并建立 cmx-biz 测试基础设施。
> **范围:** 仅数据层(Entity/Filter/Bmc/Service),不含 API Handler(阶段2)。

---

## 调研结论(影响本计划的关键事实)

1. **cmx-biz 当前无任何测试** —— 需从零搭建测试基建(`[dev-dependencies]` + `tests/`)。
2. **`DatabaseManager` 无 mock 实现** —— Service 层测试只能用真实 PG 集成测试(参照 `cmx-database/tests/integration_test.rs` 的 `setup_db_manager()`)。
3. **`domain` 模块是最完整模板** —— entity/bmc/filter/service/mod 五件套齐全,application/module 仍是占位文件。
4. **GenericCrudService 泛型:** 增删改用 `::<Bmc>::` 单参;list/page 用 `::<Bmc, Filter>::` 双参。
5. **`app_code` 重命名波及面大** —— 涉及 cmx-iam 多处 SQL 列名 + 外部 JSON key + 函数参数。**决策:阶段1 暂不动 app_code**(降低风险),挪到独立子任务评估,本阶段先建新表。

```rust
//! 测试公共辅助:数据库连接 setup
use cmx_database::{config::{DbConfig, DbType, PoolConfig, DatabaseManagerConfig}, DatabaseManager};

pub const TEST_DB_URL: &str = "postgresql://postgres:postgres@192.168.137.80:5432/postgres";
pub const TEST_DB_KEY: &str = "test_db";

/// 初始化测试数据库管理器(注册一个 Postgres 数据源)
pub async fn setup_db_manager() -> DatabaseManager {
    let pool_config = PoolConfig {
        max_connections: 5,
        min_connections: 1,
        connect_timeout: 30,
        acquire_timeout: 30,
        idle_timeout: 600,
        max_lifetime: 1800,
    };
    let db_config = DbConfig {
        db_type: DbType::Postgres,
        db_url: TEST_DB_URL.to_string(),
        db_id: TEST_DB_KEY.to_string(),
        db_schema: Some("public".to_string()),
        pool_config,
        health_check_interval: 60,
        health_check_timeout: 5,
        default: true,
    };
    let manager = DatabaseManager::new(DatabaseManagerConfig::default());
    manager
        .register_data_source(db_config)
        .await
        .expect("测试数据库连接失败,请确认 PG 可达");
    manager
}
```

```rust
        // 计算树形字段(参照 cmx-iam/src/permission/service/crud.rs:55-72)
        let (parent_code, full_path, level) = match &data.parent_id {
            Some(pid) => {
                // 查父节点,取其 parent_code/full_path/level
                let parent = GenericCrudService::<MenuBmc>::get(mm, db_id, None, pid.clone().into()).await?;
                let row = parent.first_row()
                    .ok_or_else(|| BizError::NotFound(format!("父菜单不存在: {}", pid)))?;
                let p_full_path = row.get("full_path").and_then(|v| v.as_str()).unwrap_or("").to_string();
                let p_level = row.get("level").and_then(|v| v.as_i64()).unwrap_or(1) as i32;
                let p_code = row.get("code").and_then(|v| v.as_str()).map(|s| s.to_string());
                let new_path = format!("{}/{}", p_full_path, data.code);
                (p_code, new_path, p_level + 1)
            }
            None => {
                // 根节点
                (None, format!("/{}", data.code), 1)
            }
        };

        // 开事务:INSERT 新节点 + 更新父节点 is_leaf=0
        let txn = mm.begin_txn(db_id).await?;
        // ⚠️ 以下为伪代码示意,实际需用 execute_sql_with_datavalues 在事务内执行
```

```rust
// crates/libs/cmx-core/src/model/module/manifest.rs
//! 模块迁移包清单模型
use serde::{Deserialize, Serialize};
#[cfg(feature = "openapi")]
use utoipa::ToSchema;

/// 模块聚合包清单(对应 module.manifest.json)
#[derive(Debug, Clone, Serialize, Deserialize)]
#[cfg_attr(feature = "openapi", derive(ToSchema))]
pub struct ModuleManifest {
    pub manifest_version: String,
    pub module: ModuleInfo,
    /// 迁移包版本号 = 导出时间戳 yyyyMMddHHmmSS(自动生成)
    pub package_version: String,
    #[serde(default)]
    pub resources: ModuleResources,
    #[serde(default)]
    pub plugins: Vec<ModulePluginEntry>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub checksum: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub signature_algorithm: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub signature: Option<String>,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub signer_key_id: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[cfg_attr(feature = "openapi", derive(ToSchema))]
pub struct ModuleInfo {
    pub code: String,
    pub name: String,
    pub domain_code: String,
    pub application_code: String,
    #[serde(skip_serializing_if = "Option::is_none")]
    pub description: Option<String>,
}

#[derive(Debug, Clone, Default, Serialize, Deserialize)]
#[cfg_attr(feature = "openapi", derive(ToSchema))]
pub struct ModuleResources {
    #[serde(default)]
    pub forms: Vec<String>,
    #[serde(default)]
    pub menus: Vec<String>,
    #[serde(default)]
    pub metadata: Vec<String>,
    #[serde(default)]
    pub permissions: Vec<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[cfg_attr(feature = "openapi", derive(ToSchema))]
pub struct ModulePluginEntry {
    pub id: String,
    pub version: String,
    pub package: String,
}

impl ModuleManifest {
    /// 签名载荷序列化(稳定字节,用于 checksum/Ed25519 签名)
    pub fn to_canonical_bytes(&self) -> serde_json::Result<Vec<u8>> {
        let s = serde_json::to_string(self)?;
        Ok(s.into_bytes())
    }
}
```
