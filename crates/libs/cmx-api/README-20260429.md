# cmx-api

> cmx-api 是 CMX 系统的 Web API 开发框架，基于 Axum 提供 REST API 的 Handler、路由注册、中间件和通用 CRUD 框架。

## 简介

cmx-api 模块提供 Web API 开发所需的基础组件，包括：

- **统一响应封装**：基于 `ApiResp<T>` 的标准 JSON 响应格式
- **错误处理框架**：基于 `thiserror` 的类型安全错误定义
- **中间件系统**：CORS、限流、安全头、链路追踪等
- **通用 CRUD Handler**：通过 `GenericCrudService` 实现数据库操作的 REST API
- **OpenAPI 文档**：集成 utoipa 自动生成 API 文档

## 快速开始

### 安装指南

```toml
[dependencies]
cmx-api = { workspace = true }
```

### 核心示例

#### 1. 使用通用 CRUD Handler

```rust
use cmx_api::{CmxAppState, ApiResp, rest::handler, routes::crud_routes};
use axum::{Router, routing::{get, post}};

// 定义实体和 BMC
struct MyEntity {
    id: String,
    name: String,
}

struct MyBmc;

// 实现 DbBmc trait
impl DbBmc for MyBmc {
    const TABLE_NAME: &'static str = "my_table";
    // ... 实现 required 方法
}

// 注册 CRUD 路由
pub fn routes() -> Router<CmxAppState> {
    Router::new()
        .route("/myentity", post(handler::create::<MyBmc, MyEntity>))
        .route("/myentity/list", post(handler::list::<MyBmc, MyFilter>))
        .route("/myentity/page", post(handler::page::<MyBmc, MyFilter>))
        .route("/myentity", get(handler::get_by_id::<MyBmc>))
        .route("/myentity", post(handler::update::<MyBmc, MyEntity>))
        .route("/myentity", post(handler::delete::<MyBmc>))
}
```

#### 2. 统一响应格式

```rust
use cmx_api::ApiResp;

// 成功响应
let resp = ApiResp::ok(data);

// 无数据成功响应
let resp = ApiResp::ok_no_data();

// 分页响应
let resp = ApiResp::ok_with_pagination(data, page, page_size, total);

// 失败响应
let resp = ApiResp::fail(code, "error message");
```

#### 3. 使用中间件

```rust
use cmx_api::middleware::{cors_layer, rate_limit_layer, mw_context};

let app = Router::new()
    .layer(cors_layer())
    .layer(rate_limit_layer(100, 60))  // 100请求/60秒
    .layer(mw_context())
    .route("/", get(handler));
```

## 核心功能

### 功能特性列表

| 功能 | 说明 |
|------|------|
| 统一响应格式 | `ApiResp<T>` 提供标准 JSON 响应结构 |

## 主要模块说明

### `error` - 错误处理

```rust
use cmx_api::{Error, Result, ErrCode};

// 使用错误类型
fn example() -> Result<()> {
    Err::<()>(Error::NotFound("资源不存在".to_string()))?;
    Ok(())
}
```

支持的错误类型：
- `BusinessError` - 业务错误（HTTP 200）
- `Unauthorized` - 未授权 (401)
- `Forbidden` - 禁止访问 (403)
- `NotFound` - 资源不存在 (404)
- `ValidationError` - 验证失败 (422)
- `RateLimitExceeded` - 请求限流 (429)
- `InternalError` - 内部错误 (500)

### `rest::handler` - 通用 CRUD Handler

| Handler | HTTP 方法 | 说明 |
|---------|----------|------|
| `create` | POST | 创建单个实体 |
| `create_many` | POST | 批量创建 |
| `get_by_id` | GET | 根据 ID 查询 |
| `update` | POST | 更新单个实体 |
| `update_many` | POST | 批量更新 |
| `delete` | POST | 删除实体 |
| `list` | POST | 列表查询 |
| `page` | POST | 分页查询 |

### `middleware` - 中间件

```rust
use cmx_api::middleware::{
    cors_layer,           // CORS
    rate_limit_layer,     // 限流
    mw_security_headers,  // 安全头
    mw_context,           // 上下文
    mw_trace,             // 链路追踪
};
```

## 使用指南

### 添加新的业务 Handler

1. 在 `handlers/` 下创建新模块，如 `handlers/myentity/`
2. 定义模块结构：

```
handlers/myentity/
├── mod.rs       # 模块导出
├── bmc.rs       # DbBmc 实现
├── entity.rs    # 实体定义
├── filter.rs    # 过滤条件
├── handler.rs   # Handler 实现
└── response.rs  # 响应结构
```

3. 在 `handlers/mod.rs` 中注册模块
4. 在 `openapi.rs` 中添加路由路径

### 自定义限流配置

```rust
use cmx_api::middleware::{rate_limit_layer, RateLimitConfig};

// 严格模式：100 请求/分钟
rate_limit_layer_strict(100, 60)

// 宽松模式：1000 请求/分钟
rate_limit_layer_permissive(1000, 60)

// 自定义配置
let config = RateLimitConfig {
    limit: 500,
    window: 60,
};
rate_limit_layer(config)
```

### OpenAPI 文档集成

## 常见问题

### Q: 如何处理数据库连接？

**A**: `DatabaseManager` 通过 `get_default_db_manager()` 全局获取，不需要通过 state 传递。Handler 通过请求头中的 `db_id` 指定目标数据库。

### Q: 如何自定义错误响应格式？

**A**: 实现 `IntoResponse` trait for your error type，将错误转换为 `ApiResp` 格式。

### Q: 如何添加新的中间件？

**A**: 在 `middleware/` 目录下创建新模块，实现 `Tower` 的 `Layer` 和 `Service` trait，然后在 `middleware/mod.rs` 中导出。

### Q: 为什么 `get_by_id` 使用 GET 而其他使用 POST？

**A**: REST 规范中，GET 用于查询操作且参数通过 URL 传递。其他修改操作（创建、更新、删除）使用 POST 因为需要 JSON body 传递数据。
